### 📱 Project 10: Kasir Pintar AI (Android POS)
Aplikasi kasir cerdas yang dirancang untuk mempercepat operasional transaksi. Otak kecerdasan buatan dikonfigurasi melalui **Google AI Studio**, kemudian dieksekusi secara native di Android Studio dengan antarmuka UI *Glassmorphism*.

**Fitur Unggulan:**
- 🎙️ **Voice AI Input:** Kasir dapat mencatat pesanan otomatis langsung dari suara pelanggan.
- 🧾 **Sistem Setruk Digital:** Manajemen riwayat transaksi yang rapi dan siap cetak.
- 💳 **Deteksi QRIS:** Siap untuk pelacakan pembayaran digital modern.

📥 **[Unduh & Coba Aplikasi (APK) di Sini](https://github.com/Shutdown-droid/Portofolio/releases/download/v1.0/Kasir.AI.apk)**

Aplikasi *e-commerce* Android berbasis *Augmented Reality* (**E-Commerce VR** / `com.example.e_commercevr`) dengan antarmuka modern **Jetpack Compose & Material3** bergaya *glassmorphism*, dirancang untuk menguji penempatan produk secara virtual sebelum membeli.

### ✨ Fitur & Status Rilis (v1.0)
* 🛋️ **Place Mode (Tersedia):** Menempatkan objek furnitur virtual (seperti model 3D `sofa.glb`) di ruang nyata secara *real-time* menggunakan **ARCore**, **Sceneform**, dan **Filament**, lengkap dengan kontrol gestur serta tangkapan layar (*screenshot*) AR.
* 🛍️ **Katalog, Keranjang & Riwayat Transaksi:** Arsitektur *ViewModel*, **Room Database** lokal, dan layanan API (**Retrofit**) untuk menjelajahi produk, keranjang belanja, serta catatan transaksi.
* 👕 **Try-On Mode (Roadmap Berikutnya):** Pengembangan lanjutan untuk uji coba produk *wearables* direncanakan pada iterasi berikutnya.

### 🛠️ Tech Stack
* **Bahasa & UI:** Kotlin, Jetpack Compose, Material3
* **AR & 3D Rendering:** ARCore, Sceneform, Filament, CameraX
* **Data & Arsitektur:** Room Database, Retrofit, ViewModel

### 📱 Cara Instalasi
1. Unduh file `.apk` pada bagian **Assets** di bagian bawah halaman rilis ini.
2. Buka file tersebut di perangkat Android (diuji pada Xiaomi Poco X6 5G dengan Google Play Services for AR terpasang) lalu pilih **Instal** *(izinkan instalasi dari sumber tidak dikenal jika diminta)*.
